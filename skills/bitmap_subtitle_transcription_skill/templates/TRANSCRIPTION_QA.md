# Transcription QA Checklist

- [ ] Correct source and subtitle track selected.
- [ ] Source media was not modified.
- [ ] Native PGS/VobSub asset was preserved.
- [ ] Output event count is plausible.
- [ ] SRT numbering begins at 1 and is contiguous.
- [ ] Every timestamp is syntactically valid.
- [ ] Every event has start < end.
- [ ] Events are in nondecreasing chronological order.
- [ ] No obvious unintended caption persistence across unrelated dialogue.
- [ ] No invented dialogue used to fill unreadable bitmap text.
- [ ] Uncertain readings are documented.
- [ ] Meaningful signs/non-speech cues are retained only when present in source.
