# Resume After Interruption — Generic Prompt

Resume the current bounded research unit from its durable working state.

Do not repeat completed searches, retrievals, adjudications, or coding.

First reconcile:
- authoritative predecessor identity;
- execution-status file;
- search log;
- raw captures;
- source/source-link state;
- adjudication/provenance;
- controlled changes;
- completed and partial items;
- any partial checkpoint/release artifacts.

Treat prior progress messages as expectations to check, not proof of file state.

Report missing, reverted, or conflicting artifacts before making substantive changes.

If acquisition is already complete, continue with adjudication/summary/integrity/packaging only.
If substantive work is already complete, perform packaging/validation only.

If durable storage is unavailable, stop rather than continue in temporary state.
